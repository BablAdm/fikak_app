# Fikak App - User Testing Guide

**Welcome! This guide will help you test the Fikak App as an end user.**

---

## Quick Start (3 Steps)

### 1. Start the Application

Open a terminal and run:

```bash
cd fikak_app  # your cloned repository root
./setup.sh
```

**Wait 2-3 minutes** for all services to start. You'll see a success message when ready.

### 2. Install the Fikak Custom App

```bash
./install-fikak-app.sh
```

Choose option 1 or 2 based on your SSH setup. This installs the custom API endpoints.

### 3. Open Your Browser

Navigate to **http://localhost**

**Login with:**
- Username: `Administrator`
- Password: the `ADMIN_PASSWORD` value in your `.env` (generated by setup.sh)

### ✅ Test 1: Login & Dashboard (2 minutes)

**Steps:**
1. Open http://localhost in your browser
2. Enter username `Administrator` and the `ADMIN_PASSWORD` value from your `.env`

### ✅ Test 4: Eligibility Check Workflow (5 minutes)

> ⚠️ **Use synthetic data only.** Never enter real national IDs, bank account
> numbers, or property/deed identifiers in this test environment, and redact
> any personal data from screenshots before sharing them.

**Steps:**
1. Navigate to "Eligibility Check" from the menu
2. Start a new eligibility check
3. Follow the multi-step wizard:
   - **Step 1**: Enter national ID or personal details
   - **Step 2**: Nafath verification (simulated in test mode)
   - **Step 3**: Bank account selection (via Tarabut integration)
   - **Step 4**: Property/Deed details
   - **Step 5**: Review and submit

**Expected Result:**
- Each step should load properly
- You should be able to move forward/backward
- Form validation should work (required fields, format checks)
- Final step shows eligibility result

**Note any issues or errors** ✓

## Reporting Issues

### When you find a bug, please note:

1. **What were you doing?** (Steps to reproduce)
2. **What did you expect to happen?**
3. **What actually happened?**
4. **Screenshot or error message** (if any)
5. **Browser and version** (Chrome 120, Safari 17, etc.)
6. **Device type** (Desktop, Mobile, Tablet)

### Example Bug Report:

```
ISSUE: Login button doesn't work on mobile

Steps to reproduce:
1. Open http://localhost on iPhone (Chrome)
2. Enter username and password
3. Click "Login" button

Expected: Should log in and go to dashboard
Actual: Button click does nothing

Screenshot: [attach image]
Browser: Chrome Mobile 120.0.6099.43
Device: iPhone 13, iOS 17.1
```

## Troubleshooting

### If the app won't load:

```bash
# Check if services are running
docker-compose -f docker-compose.unified.yml ps

# Restart if needed
docker-compose -f docker-compose.unified.yml restart

# View logs
docker-compose -f docker-compose.unified.yml logs -f fikak_ui
```

### If you see errors:

1. Open browser DevTools (F12)
2. Go to Console tab
3. Copy any red error messages
4. Share with the development team

### If login doesn't work:

```bash
# Reset the admin password (choose a NEW password - do not reuse 'admin';
# update ADMIN_PASSWORD in .env to match)
docker exec -it fikak_backend bench --site localhost set-admin-password <new-password>
```

## Stopping the Application

When you're done testing:

```bash
# Stop all services
docker-compose -f docker-compose.unified.yml down

# Stop and remove all data (clean slate)
docker-compose -f docker-compose.unified.yml down -v
```
